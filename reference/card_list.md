# Lister les fiches du corpus

Lister les fiches du corpus

## Usage

``` r
card_list(...)
```

## Arguments

- ...:

  Filtres de facette, en français ou en anglais : \`phenomenon = "basses
  eaux"\`, \`output = "serie"\`, \`statistic = "change"\`.

## Value

Un data.frame, une ligne par variable.
